# Landing page artwork: ChatGPT image prompts

How to use:
1. In ChatGPT, start each new image with the **style block** below, then the image prompt.
2. Ask for the size shown (ChatGPT supports square 1:1, landscape 3:2 and portrait 2:3).
3. Save each image with the file name shown, then upload them to Claude in batches.

Do NOT generate: customer photos for reviews, or a "our team / our workshop" photo. Use real photos for those.

---

## Style block (paste before every prompt)
```
Professional e-commerce product photography for a custom patch company. Soft studio lighting, warm cream background (#FFF6E6), subtle soft shadow, high detail, sharp focus, realistic thread and material textures. Brand colors used in the patch designs: navy #10264B, teal #1C8FA8, orange #F7931E, red #E23B2E, yellow #FFC93C. Absolutely no text, no letters, no numbers, no words, no logos, no brand names, no watermarks anywhere in the image.
```
